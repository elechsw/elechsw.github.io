PLC 기반 컨베이어벨트 자동화 시스템

투입물을 감지해 자동으로 이송·정지시키는 컨베이어벨트를 PLC로 제어하고, X3DOM과 Three.js로 조립 형상을 단계별로 시각화한 캡스톤 프로젝트입니다.

제어반 상태 · RUN
01

프로젝트 개요

본 프로젝트는 생산 라인의 반복 이송 작업을 자동화하는 소형 컨베이어벨트를 설계하고, PLC 래더 로직으로 투입 감지부터 정지까지의 동작을 제어하는 것을 목표로 합니다.

기구부는 프레임·롤러·벨트·구동 모터로 구성하고, 제어부는 광센서 입력을 받아 모터 출력을 결정하는 방식으로 설계했습니다. 실제 조립 전 형상 검토를 위해 X3DOM으로 개념 모델을, Three.js로 세부 조립 모델을 웹에서 확인할 수 있도록 구성했습니다.

PLCLS XGB, 24V DC I/O
구동 모터3상 유도전동기 0.75kW
감지 센서포토센서 E3F 시리즈
벨트 폭200 mm
이송 속도0.3 m/s
02

시스템 구성

입출력 신호와 전체 동작 흐름을 정의합니다.

입력 (Input)
주소설명
X00투입 감지 센서
X01정지 위치 센서
X02비상정지 버튼
X03수동/자동 전환 스위치
출력 (Output)
주소설명
Y00컨베이어 구동 모터
Y01경고등 / 부저
Y02배출 실린더 (선택)
03

3D 모델링

개념 검증부터 완성 조립까지, 두 가지 도구로 형상을 단계적으로 구현합니다.

먼저 X3DOM으로 프레임과 롤러의 기본 치수를 빠르게 확인한 뒤, Three.js로 옮겨와 롤러·벨트·구동부·센서·제어반을 순서대로 쌓아 올리며 전체 조립 형상을 완성합니다.

X3DOM · 개념 검증 Three.js · 인터랙티브 조립

개념 모델 · X3DOM

프레임과 롤러의 배치, 벨트 베드 폭을 확인하기 위한 초기 형상입니다. 드래그로 회전, 휠로 확대/축소할 수 있습니다.

조립 모델 · Three.js

단계를 선택하면 해당 구성품이 순서대로 추가됩니다. 캔버스는 드래그로 회전할 수 있습니다.

1단계 · 프레임 구조 — 각파이프로 다리와 상부 레일을 구성해 벨트를 지지할 기본 골조를 만듭니다.

각파이프 30×30 전고 450 mm
04

동작 시퀀스

투입부터 정지까지 PLC 래더 로직이 처리하는 순서입니다.

자동 모드 시작

X03 자동 전환 후 시작 스위치를 누르면 대기 상태로 전환합니다.

투입 감지

X00 센서가 물체를 감지하면 Y00 모터가 구동을 시작합니다.

이송 & 정지 판단

X01 정지 위치 센서 감지 시 Y00을 OFF하고 다음 공정 신호를 대기합니다.

예외 처리

X02 비상정지 입력 시 전 출력을 차단하고 Y01 경고등을 점등합니다.
